# Controle-de-Registros
## Adaptado SIGOC — Sistema de Gestão Operacional

Projeto de desenvolvimento e aprimoramento de sistema realizado em colaboração com a Guarda Municipal da Prefeitura de Guapimirim (RJ), com foco na modernização dos processos de registro de ocorrências, consulta e gerenciamento de informações operacionais.

O trabalho envolve melhorias na arquitetura da aplicação, centralização do acesso aos dados e evolução das funcionalidades para permitir maior integração entre os computadores utilizados na operação.

*Este repositório apresenta uma versão demonstrativa do projeto, destinada à apresentação das soluções técnicas desenvolvidas. Não contém dados operacionais reais nem informações confidenciais da instituição.*
